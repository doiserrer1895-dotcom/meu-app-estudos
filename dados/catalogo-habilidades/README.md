# Catálogo de Árvores de Habilidades

Este diretório guarda as definições de referência das árvores do aplicativo.

- `catalogo-habilidades.json`: seis árvores, conquistas, descrições, custos, atributos e regras visuais/de desbloqueio.
- Este material está arquivado em uma branch separada e **não está conectado ao funcionamento do aplicativo**.
- Nenhuma automação de detecção por texto, preenchimento automático ou sugestão foi ativada.
- A árvore Vitalidade já está no código principal; este catálogo apenas preserva sua definição junto das demais para trabalho futuro.
- A árvore Finanças mantém no código atual o último custo de 35 pontos; o padrão das outras árvores é 32.

Use este catálogo como referência ao planejar a próxima etapa, sem substituir os dados personalizados dos usuários.
